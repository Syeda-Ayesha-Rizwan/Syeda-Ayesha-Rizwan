### 1️⃣ **ITOS - Intelligent Transportation Optimization System** 🚗
*Real-world calculus application for vehicle fuel optimization*

```
📊 Application Type: Desktop Application (Java Swing)
🇵🇰 Domain: Pakistan Transportation Sector
📈 Mathematical Focus: Calculus, Derivatives, Optimization
```

#### **Tech Stack:**
![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=java)
![Swing](https://img.shields.io/badge/Swing-ED8B00?style=flat-square)
![Calculus](https://img.shields.io/badge/Calculus%20Algorithms-FF6B6B?style=flat-square)
![Data Visualization](https://img.shields.io/badge/Live%20Graphs-00D9FF?style=flat-square)

#### **Key Features:**
- 🔢 **Calculus Engine:** Fuel model F(v) = av² + b/v + c with derivative optimization
- 🇵🇰 **Pakistan-Specific Data:** 7 real vehicles (Suzuki Mehran, Honda Civic, Toyota Corolla, etc.) with actual fuel prices in PKR
- 📊 **Interactive Dashboard:** Real-time fuel cost, time, CO₂ metrics with live graphs
- 🎯 **Optimal Speed Calculation:** v* = (b/2a)^(1/3) - derived from calculus
- 🏛️ **Policy Simulator:** National-level impact calculations for hypothetical speed limits
- 📈 **Performance Meters:** Fuel economy, time efficiency, CO₂ impact scores (0-100)
- 💾 **Export Options:** CSV data export, HTML reports, print preview, vehicle comparisons
- 🧪 **Experiment Mode:** Modify constants a, b, c in real-time and visualize changes
- 🎨 **Premium UI:** Dark/light theme toggle, keyboard shortcuts, responsive design

#### **Mathematical Basis:**
```
Fuel Consumption:       F(v) = av² + b/v + c
First Derivative:       dF/dv = 2av - b/v²
Critical Point:         v³ = b/2a
Optimal Speed:          v* = (b/2a)^(1/3)
Second Derivative:      d²F/dv² = 2a + 2b/v³ > 0 (minimum check)
Trade-off Cost:         G(v) = α·F(v) + β·T(v)  [T(v) = D/v]
```

```
                                        │ • Vector embeddings          │
                                        │ • Semantic similarity search │
                                        │ • User data & auth tokens    │
                                        └──────────────────────────────┘

                        🐳 Docker Compose (Local Development)
```

#### **Key Features:**
- 🧠 **Knowledge Base:** Store and organize personal documents/notes
- 🤖 **AI Summaries:** GPT-4o generates intelligent summaries of content
- 🔍 **Semantic Search:** Find relevant knowledge using vector embeddings
- 📝 **RAG System:** Retrieve Augmented Generation for context-aware responses
- 🔐 **User Authentication:** NextAuth.js with JWT tokens
- ⚡ **Async Backend:** FastAPI for high-performance, concurrent requests
- 📊 **Vector Database:** PostgreSQL with pgvector for similarity search
- 🐳 **Containerized:** Docker Compose for easy local development
- 📱 **Modern Frontend:** Next.js 16 with App Router for optimal UX
- 🔄 **Real-time Updates:** Server-sent events for live knowledge updates

#### **How It Works:**
```
1. User uploads document → FastAPI processes & extracts text
2. OpenAI API generates embeddings → Stored in pgvector
3. User searches → Vector similarity search returns top matches
4. GPT-4o creates summary → Contextual response delivered
5. Results cached → Efficient subsequent searches
```
